# 📞 Call Center KPI Analysis Project

## 📌 Overview
This project simulates and analyzes key performance indicators (KPIs) for a call center. It covers the entire data pipeline:
- Generating synthetic data using Python
- Calculating important KPIs (e.g., resolution rate, satisfaction rate, call duration)
- Storing data in an SQLite database
- Visualizing the insights in Power BI

---

## 🎯 Objectives
- Practice working with call center data
- Analyze core customer experience KPIs
- Use end-to-end tools including Python, SQLite, and Power BI
- Build a portfolio-ready project to showcase analytical and technical skills

---

## 🛠 Tools and Technologies
- **Python**: Data generation, KPI calculation
- **Faker**: Synthetic data creation
- **Pandas / NumPy**: Data manipulation and analysis
- **SQLite3**: Storing structured data in a lightweight database
- **Power BI**: Dashboard and visual analysis

---

## 🔧 Why Use Faker?
To simulate a realistic call center environment without using sensitive or real-world data:
- 🔐 Ensures data privacy & portfolio safety
- 🧪 Enables realistic scenarios for deeper KPI analysis
- 🚀 Highly flexible & customizable for different test cases

## 📁 Project Structure
```
Call_Data_Analysis/
│
├── generate_data.py       # Generate synthetic call center data
├── analyze_kpis.py        # Calculate key performance indicators
├── store_data.py          # Store the dataset into SQLite database
├── main.py                # Main runner script
├── call_center_data.csv   # Generated dataset
├── call_center.db         # SQLite database
└── README.md              # Project documentation (this file)
```

---

## ✅ How to Run
1. Install requirements: `pip install faker pandas numpy`
2. Run the main script: `python main.py`
3. Open Power BI and connect to the `call_center.db` file
4. Start analyzing and visualizing KPIs!
